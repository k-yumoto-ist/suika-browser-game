# Drop Merge

A mobile-first browser game inspired by falling merge puzzles.

## Run

Open `index.html` in a browser. The game is built as static files.

Matter.js is loaded from a CDN, so the first page load needs network access.

## Controls

- Mobile: move your finger left or right, then tap to drop
- Desktop: move the mouse left or right, then click to drop
- Matching balls merge into the next size
- The game ends when settled balls stay above the red line

## Publish

Host this folder with GitHub Pages, Netlify, Cloudflare Pages, or another static hosting service.
